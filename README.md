============================================================
              🧮 CALCULADORA EM LINGUAGEM C
============================================================

Um projeto simples e eficiente para realizar operações 
matemáticas básicas diretamente no seu terminal.

------------------------------------------------------------
✨ FUNCIONALIDADES
------------------------------------------------------------
● Soma (+)
● Subtração (-)
● Multiplicação (*)
● Divisão (/) com trava de segurança para zero

------------------------------------------------------------
🚀 COMO COMPILAR E USAR
------------------------------------------------------------

Certifique-se de ter o GCC instalado no seu sistema.

1. ACESSE A PASTA DO PROJETO:
   $ cd caminho/da/sua/pasta

2. COMANDO DE COMPILAÇÃO:
   $ gcc calculadora.c -o calculadora

   > O comando acima gera um executável chamado 'calculadora'.

3. EXECUÇÃO:
   Linux/macOS:
   $ ./calculadora

   Windows:
   $ calculadora.exe
